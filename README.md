# Random Number Game

Ein kleines Zahlenratespiel in Python mit grafischer Benutzeroberfläche.

Der Computer wählt zufällig eine Zahl zwischen **1 und 10**. Der Spieler versucht, diese Zahl zu erraten und hat dafür **4 Leben** zur Verfügung.

## Features

- 🎲 Zufällige Zahl zwischen 1 und 10
- ❤️ 4 Leben pro Spiel
- ✅ Richtige Zahl beendet das Spiel mit einem Sieg
- ❌ Falsche Zahl kostet ein Leben
- ⚠️ Ungültige Eingaben werden erkannt
- 🖥️ Grafische Benutzeroberfläche mit Tkinter
- 🔒 Eingabefeld und Button werden nach Spielende deaktiviert

## Technologien

- **Python 3**
- **Tkinter** – grafische Benutzeroberfläche
- **Random** – Generierung der Zufallszahl
